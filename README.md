# Homebrew tap for Euphoria

Euphoria detects the key, BPM and energy of a track, so a DJ can mix in key. This tap holds the Homebrew formula of the command line tool and the cask of the macOS app.

Add the tap once:

```
brew tap lvndry/euphoria
```

Install the command line tool:

```
brew install euphoria
```

Install the app:

```
brew install --cask euphoria
```

The Euphoria Release workflow updates the formula and the cask after each release; those files are generated, so do not edit them by hand.
