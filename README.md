# Homebrew tap for Euphoria

Euphoria detects the key, BPM and energy of a track, so a DJ can mix in key. This tap holds the Homebrew formula of the command line tool and the cask of the macOS app.

Install the command line tool:

```
brew install lvndry/euphoria/euphoria
```

Install the app:

```
brew install --cask lvndry/euphoria/euphoria
```

This repository is updated by the Euphoria Release workflow after each release. The files are generated; do not edit them by hand.
